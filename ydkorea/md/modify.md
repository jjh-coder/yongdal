**콘플라워 블루 + 주황 CTA + 따뜻한 흰 배경** 조합을 추천해요. 장년층은 수정체가 누렇게 변하고 대비 감도가 떨어져서, 채도 높은 파스텔이나 회색 계열 글씨가 특히 읽기 어려워요. 그래서 아래 값들은 모두 대비율(WCAG)을 계산해서 골랐어요. 일반 기준은 4.5:1이고, 고령층 대상이면 7:1 안팎이 안전해요.

| 용도 | 색상 | 대비율 | 비고 |
|---|---|---|---|
| 본문 글씨 | `#1A1A1A` | 배경 `#FAF8F5` 위 **16.4:1** | 순수 검정 대신 약간 부드러운 검정 |
| 보조 글씨 | `#595959` | 흰 배경 위 **7.0:1** | 이보다 연한 회색은 쓰지 않기 |
| 주조색 (메뉴, 제목, 링크) | `#6495ED` 콘플라워 블루 | 흰 글씨 **3.0:1**, 어두운 글씨(`#1A1A1A`) **5.9:1** | 밝은 색이라 배경 위 글씨는 어두운 글씨 사용 |
| 주조색 hover, 작은 글씨 링크 | `#4169E1` 로열 블루 | 흰 글씨 **4.9:1** | |
| 전화 CTA | `#C2410C` 주황 | 흰 글씨 **5.2:1** | 화면에서 가장 눈에 띄는 색 |
| CTA hover | `#9A3412` | 흰 글씨 **7.3:1** | |
| 페이지 배경 | `#FAF8F5` 따뜻한 흰색 | | 순백보다 눈부심이 적음 |
| 카드/표 배경 | `#FFFFFF` | | |
| 안내 박스 배경 | `#EAF1FD` 연한 파랑 | 본문 글씨 **15.5:1** | "상담 전 안내" 같은 박스 |
| 입력창 테두리 | `#8A8F98` | 흰 배경 **3.3:1** | 입력창은 경계가 분명해야 해요 |
| 오류/경고 | `#B91C1C` | 흰 글씨 **6.5:1** | |

**이 조합의 이유**
- 파랑(시원함)과 주황(따뜻함)은 보색에 가까워 색을 구분하기 어려운 분들도 역할을 알아볼 수 있어요.
- 용달·화물 업종에서 흔한 파란색과 달라서 기존 사이트와도 인상이 달라져요.
- 주황은 노란 필터가 낀 시야에서도 잘 보이는 편이에요.

**이전 문서에서 바로잡을 점**
앞서 제안한 CTA 색 `#F59E0B`(노란 주황)는 흰 글씨를 올리면 대비가 많이 낮아요. 이 색을 쓰려면 글씨를 `#1A1A1A`로 해야 하는데(8.1:1), 이번 조합처럼 진한 주황에 흰 글씨를 쓰는 쪽이 더 안정적이에요.

**함께 지킬 규칙**
- **색만으로 의미를 전달하지 않기**: 성공/오류는 색과 함께 아이콘, 문구("오류:")를 같이 써요. 적록색약이 있는 분들이 초록과 빨강을 헷갈릴 수 있어요.
- **본문 18px**을 권장해요. (지금 문서는 16px 최소로 되어 있어요.) 보조 글씨도 15px 아래로는 내리지 않는 게 좋아요.
- **연한 회색 글씨, 이미지 위에 얹은 글씨, 그라데이션 배경 위 글씨**는 금지하세요.
- 메뉴·링크는 색뿐 아니라 **굵기나 밑줄**로도 구분하면 좋아요.
